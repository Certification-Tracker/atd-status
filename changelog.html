ATD QAG/LOA Status

Release log

1.0.0 · October 2026

  • First release: each ATD device's current FAA approval (approved QAG, approval date, expiry and status), grouped BATD then AATD.
  • Status tags: Current (more than 365 days to expiry), Expires Soon (365 days or less) and Expired (past the expiry date).
  • Device pages with the current LOA and QAG, viewed in the app without the browser's PDF toolbar, or in a new window.
  • Download button for each LOA and QAG. Files are named by device, version and document, for example TD_TD2_v3.3_QAG.pdf.
  • Previous versions of each device's LOA and QAG, marked as superseded.
  • Search box for devices.
  • Can be installed as the "ATD QAG/LOA Status" app from Edge or Chrome.
